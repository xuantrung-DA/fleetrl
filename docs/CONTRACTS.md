# Internal implementation contracts

Shared dataclasses live in `types.py`, configuration in `config.py`. Do not silently change field names across modules. Root owns these contracts.

- `Simulator(config: FleetConfig)`: `reset(seed=None,tape:EventTape|None=None)->Snapshot`, `snapshot(delay_s=0.0)->Snapshot`, `submit_plan(plan:DecisionPlan)->dict` with accepted/rejected records, `advance(seconds:float)->dict` deltas. Public `robots:dict[int,Robot]`, `tasks:dict[int,Task]`, `ports:dict[int,Port]`, `bookings:list[ChargeBooking]`, `booking_history:list[ChargeBooking]`, `warehouse:GridMap`, `time_s`, `counters:dict[str,float]`, `events:list[dict]`, `tape:EventTape`. `inject_event(event:ScenarioEvent)` is supported. Simulator owns live state; snapshots contain isolated copies. `counters` minimum consumed_wh,grid_wh,completed,collisions,edge_conflicts,energy_emergencies,reserve_violations,deadlocks,deadlocks_resolved,deadlocks_unresolved,distance_m. Counter names must be stable.
- `FleetOptimizer(config)`: `decide(snapshot:Snapshot,profile_id:int=0)->DecisionPlan`; decides according to config.controller hybrid/fixed/heuristic and config.advanced_charging. Uses map geometry from maps.py and energy.py. No live simulator state/future tape.
- `FleetEnv(config:FleetConfig|None=None, render_mode=None)`: Gymnasium Dict observation with keys `robots` (20,14),`robot_mask`(20,),`tasks`(40,10),`task_mask`(40,),`ports`(4,6),`port_mask`(4,),`global`(40,). All float32 scaled finite Boxes; action Discrete6. `reset(seed,options)` optionally options['tape']; `step(action)` returns obs,reward,terminated,truncated,info; `info['metrics']` end-of-episode metrics, `info['reward_components']` each step, `info['decision']` serializable plan. Public `.sim`, `.config`, `.optimizer`, `.metrics()` and `.snapshot()`.
- RL agent owns `rl.py`: `train(env_config, train_config, output_dir, resume=None)->dict`; `load_policy(path,device='cpu')`; `evaluate_checkpoint(path,env_config,seeds,output_dir=None)->list[dict]`; may expose helpers. Use callbacks and no test seeds for selection. Root CLI calls these APIs.
- `maps.py`: root owns `make_map(config)->GridMap`, `shortest_path(warehouse,start,goal,blocked=None)->list[Cell]|None`, `distance(...) -> float` (inf if unreachable). `scenario.py`: `generate_tape(config,warehouse,seed)->EventTape`, `make_robots(config,warehouse,seed)->list[Robot]`, `save_tape/load_tape`, `scenario_config(name,base=None)->FleetConfig`.
- `energy.py`: root owns `travel_time(robot,distance_m,config)->float` (per-cell rounded), `energy_for(robot,distance_m,elapsed_s,load_kg,config)->float`, `charge_duration(robot,energy_wh,target_soc,power_w,config)->float`, `charge_step(robot,power_w,dt,config)->tuple[net_wh,grid_wh]`, `reserve_wh(robot,config)->float`. All calculate consistent physical units. Charge duration excludes docking which caller must add.
- Root owns env.py observations.py metrics.py cli.py maps.py scenario.py energy.py and packaging. Agents own only assigned files, communicate changes early.
# v2 additions

Current interfaces and acceptance commands: [READY_TO_TRAIN.md](READY_TO_TRAIN.md). Each of the 14 variants has a stable registry ID and its own method module. Shared candidate generation and live admission remain the physical authority; learned actions never modify hard guards.

Checkpoint schema 2 binds algorithm, action/observation schema, charging mode, seed, steps, optimizer/replay state and content digests. Metadata or replay loss is an error. Resume starts new simulator episodes; it is not an exact trajectory continuation. Report schema 2 distinguishes complete, partial, failed and absent runs and keeps undefined metrics null. Known v1 replay schema remains readable.

The 250 ms budget includes observation preparation and policy inference. MILP uses exact resource-row separation and checks the complete incumbent calendars; an optimum of a relaxed problem is not emitted unless those checks pass. MPC's route projection is an approximate planning model with at most two operations, causal forecast and first-operation-only commit.
