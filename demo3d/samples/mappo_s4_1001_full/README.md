# Replay thật đầy đủ

MAPPO dispatch, S4, seed 1001, 3.600 giây mô phỏng, 7.201 frame, complete, không can thiệp. Nguồn `runs/demo3d/748f38c95f4e/replay.jsonl`. Gzip giữ nguyên byte gốc; kiểm tra provenance.json. Header là trạng thái lúc bắt đầu, recording.json là trạng thái kết thúc. Đây là minh họa phiên chạy cụ thể, không phải bằng chứng thuật toán luôn tốt hơn.

`complete` nghĩa là phiên chạy hết horizon; không có nghĩa mọi đơn hàng đều hoàn thành. MiB = 1.048.576 byte; giây ở đây là thời gian mô phỏng.
